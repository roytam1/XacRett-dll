 usage : A> yzenc [-d|-dOutDirName] [-p|-pPassWord] <FileName.txt|DirName>
       : A> yzenc FileName.txt           (ファイル'FileName.txt'を圧縮)
       : A> yzenc DirName                (ディレクトリ'DirName'を圧縮)
       : A> yzenc -d FileName.txt        (圧縮して選択ディレクトリに出力)
       : A> yzenc -dC:\TMP\ FileName.txt (圧縮してディレクトリ'C:\TMP\'に出力)
       : A> yzenc -p FileName.txt        (その都度パスワードを指定して圧縮)
       : A> yzenc -pPASSWD FileName.txt  (パスワードに'PASSWD'を指定して圧縮)
